npx serve . o python -m http.server 8080 y abre http://localhost:8080/player-cinelatino.html
Listo. Usa "Usar Proxy" para mayor compatibilidad.
Cómo funciona:
1. La URL /stream/?data=... hace redirect → od.lk → web.opendrive.com (MP4 real)
2. Usar Proxy manda esa URL a tu Cloudflare Worker para evitar CORS y problemas de referer.
3. Si tu proxy no sigue bien los redirects, prueba poniendo la URL final de OpenDrive que te devuelva el script de resolve.
